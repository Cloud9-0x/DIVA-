DIVA BIRTHDAY GITHUB PAGES SITE

1. Unzip DIVA_GitHub_Site.zip.
2. Create a PUBLIC repository on https://github.com/new (for example: diva-birthday).
3. Upload index.html AND the entire photos folder. Keep the folder name 'photos'.
4. Commit changes.
5. Repository Settings > Pages > Deploy from a branch > main > /(root) > Save.
6. Wait a few minutes, then open https://YOUR-USERNAME.github.io/diva-birthday/
7. Test the PIN: 2205.

IMPORTANT:
- The PIN screen is a cute reveal, not strong security. The files are public when hosted on a public GitHub Pages site.
- Photos are included in the photos folder. Do not upload only index.html.
- The music button opens the song on YouTube; automatic playback is blocked by many browsers and a playable audio file was not provided.
